# Insert Random

When we insert items randomly, expected height of BST is O(logN), which is the same as
built-in TreeMap which uses Red-Black Tree.

# Insert in Order

When we insert in order, height of BST is the worst case O(N), which is far worse than
built-in TreeMap which uses Red-Black Tree that guarantees to be O(logN).

| number of items | BSTMap | ULLMap | built-in TreeMap | built-in HashMap |
|      5000       | 0.10s  | 0.12s  |      0.00s       |       0.00s      |
|      10000      | 0.33s  | 0.36s  |      0.00s       |       0.00s      |
|      20000      | 1.08s  | 1.51s  |      0.00s       |       0.00s      |
|      40000      | 3.22s  | 6.09s  |      0.01s       |       0.01s      |
|      80000      | 6.20s  | 16.49s |      0.02s       |       0.02s      |
